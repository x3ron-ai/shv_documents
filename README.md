# Система автоматического формирования отчетных документов

Веб-приложение для создания отчетных документов с возможностью добавления текста и изображений. Готовый документ можно скачать в формате .docx.

## Функционал:
- Добавление текста  
- Вставка изображений  
- Скачивание документа в формате .docx  

## Планируемые обновления:
- Расширенные возможности форматирования текста и работы с отступами  
- Добавление системы регистрации пользователей  
- Подключение базы данных для хранения документов
